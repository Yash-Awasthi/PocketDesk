# PocketDesk daemon

The Node side of PocketDesk: it runs AI coding agents and desktop tools on a Windows PC in
real PTYs, serves the WebSocket API that the phone app and the browser hub talk to, and
carries the desktop stream, the file surface and the pairing flow.

- Entry point: `src/index.js` (`npm start`). `src/daemon.js` boots, `src/server.js` serves.
- The `pocketdesk` command: `src/cli.js` (`status`, `stop`, `pair`, `record`, `send`).
- Environment probes: `node src/doctor.js`.
- Tests: `npm test` — 58 files, loopback only (see `test/helpers.mjs`).
- Install and uninstall on a real PC: `scripts/install-service.ps1`, `uninstall-service.ps1`,
  documented in `../docs/SETUP-PC.md`.

Handlers live in `src/handlers/`; each module is a factory that returns an object keyed by
message type, and `handle()` in `src/server.js` dispatches on `handlers[msg.type]`.
